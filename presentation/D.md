## 3. 시연 (A 파트에서 이어서 · 약 1분)
1. A가 `shared/fixtures/`의 쿠팡·네이버 2026-08/09 CSV 4개를 올리고 분석을 완료한 화면에서 시작합니다.
2. **"광고 효율이 가장 안 좋은 플랫폼 어디야?"** 를 한 번 전송합니다.
3. 답표 첫 행 **쿠팡 291.7%**, 다음 행 **네이버 347.2%**와 근거 / 확인 항목 / 행동 제안 / 한계를 짚습니다. JSON 계획은 `metric=roas, group_by=platform, sort=asc`입니다.
4. 화면의 숫자가 코드 계산 결과라는 점과 원인을 확정하지 않는다는 점을 말한 뒤 C의 잘못된 파일 시연으로 넘깁니다.

- 이미 분석한 화면에서 질문만 보내면 planner·insight 단계가 실행됩니다. 반복 전송하지 않고 **실제 AI 리허설은 1회**로 제한합니다. 응답 시간은 네트워크·모델에 따라 달라집니다.
- 미지원 질문 **"최근 3개월 매출 합계 알려줘"** 와 인사 **"안녕!"** 는 별도 검증 완료입니다. 발표 시간이 부족하면 추가 입력 대신 검증 기록을 설명합니다. 인사·기능 안내는 LLM을 호출하지 않습니다.
- 기존 CSV 질문 결과와 새 Excel 질문 결과를 섞지 않습니다. Excel 4개는 합산매출 **53,501,670원**, 쿠팡 ROAS **551.8%**(광고 전환매출 14일 기준), 네이버 **357.9%**입니다. 샘플 검증이지 실제 판매 데이터 검증은 아닙니다.
