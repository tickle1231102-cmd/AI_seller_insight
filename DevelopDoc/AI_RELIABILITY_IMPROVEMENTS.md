## 구현한 다섯 가지
1. **근거와 문장의 연결** — 계산 결과를 출처 경로·기간·대상·지표·값·단위로 묶는다. AI는 내부 `InsightSelection`의 ID만 선택하고, 서버가 최종 문장을 만든다. 다른 플랫폼의 숫자를 가져와 새 주장을 쓰는 생성 경로를 제거했다. 여러 경로에서 같은 근거가 들어오면 표시 문장은 중복 제거한다.
2. **사실/확인/행동/한계 구분** — summary/evidence는 계산 근거 문장, checks/actions는 해당 데이터와 신호에 허용된 점검 문구로 제한했다. 원인 단정이나 임의의 목표치를 모델이 직접 출력할 수 없다. 필요한 추가 자료는 limitations에 서버가 명시한다.
3. **답변 가능성 확인** — 이전 기간 없음, 계산 불가 ROAS, 연속되지 않은 비교 월, 신호 없음, 질문 결과 없음, 같은 범위의 상충 값 등을 확인한다. 실제 0과 결측값을 구분한다. 질문 결과 없음과 상충 값은 유료 호출 전에 차단한다.
4. **질문 조건 누락 방지** — 명시한 지표/분류/정렬/개수/연·월을 추출해 모델 계획과 대조한다. 현재 계약에 없는 플랫폼·상품 필터, 범위 기간, 여러 지표, 이익/CTR/CPC/CVR 등은 안내한다. 모델도 표현하지 못한 조건을 내부 unrepresented_constraints로 반환한다.
